# Learning GitHub Copilot

GitHub Copilot is an AI pair programmer that suggests code directly inside your editor.

## Topics

- **Setup** – Installing the Copilot extension in VS Code / JetBrains
- **Inline Suggestions** – Accepting and refining AI code suggestions
- **Copilot Chat** – Asking questions about your codebase
- **Slash Commands** – `/explain`, `/fix`, `/tests`, `/doc`

## Getting Started

1. Install the **GitHub Copilot** extension from the VS Code marketplace.
2. Sign in with your GitHub account (free trial available).
3. Open any file and start typing — watch Copilot suggest completions.

## Useful Slash Commands (Copilot Chat)

| Command | Description |
|---|---|
| `/explain` | Explain selected code |
| `/fix` | Suggest a fix for selected code |
| `/tests` | Generate unit tests for a function |
| `/doc` | Generate documentation comments |

## Exercise

1. Open an existing project file.
2. Use `/explain` on a function you find complex.
3. Use `/tests` to generate unit tests for it.
4. Ask Copilot Chat: *"How can I improve the performance of this function?"*
