# Learning Claude AI

Claude is an AI assistant by Anthropic. This section covers how to make the most of Claude for coding and problem-solving.

## Topics

- **Prompting Techniques** – How to write clear, effective prompts
- **Code Generation** – Asking Claude to write and explain code
- **Debugging** – Using Claude to find and fix bugs
- **Code Review** – Getting Claude to review your pull requests
- **Documentation** – Generating docs and comments with Claude

## Quick Tips

| Goal | Prompt Pattern |
|---|---|
| Explain code | "Explain this code step by step: `<code>`" |
| Generate code | "Write a Python function that `<task>`" |
| Debug | "Why does this code throw `<error>`? `<code>`" |
| Refactor | "Refactor this code to be more readable: `<code>`" |

## Example Exercise

Ask Claude to build a simple CLI to-do app in Python, then:
1. Add a feature yourself.
2. Ask Claude to review your addition.
3. Apply the feedback and iterate.
