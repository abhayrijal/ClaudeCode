# Hands-On Gen-AI Projects

Put your AI-assisted coding skills into practice! Each project here is designed to be built collaboratively with Claude (or any AI tool of your choice).

## Project Ideas

| Project | Tools | Difficulty |
|---|---|---|
| AI-powered CLI notes app | Claude, Python | Beginner |
| Chatbot with memory | ChatGPT API, Python | Intermediate |
| Code review bot | Claude API, GitHub Actions | Intermediate |
| Image captioning web app | Gemini, Flask | Intermediate |
| Autonomous coding agent | Claude, LangChain | Advanced |

## How to Start a Project

1. Choose a project from the table above (or invent your own).
2. Create a new folder: `Projects/<your-project-name>/`.
3. Add a `README.md` describing the goal and tech stack.
4. Build iteratively — commit frequently and ask Claude for help.

## Tips for Working with AI Assistants

- **Be specific** in your prompts; include context and constraints.
- **Iterate** — treat the first AI response as a draft.
- **Verify** — always review and test AI-generated code before using it.
- **Learn** — ask the AI to explain code you don't understand.
