# AI Tools Learning Hub

Welcome to the AI Tools Learning Hub! This directory is your starting point for exploring and learning different AI tools with Claude as your coding assistant.

## Directory Structure

```
AI-Tools/
├── Claude/          - Learning Claude AI capabilities and prompting
├── ChatGPT/         - Exploring OpenAI's ChatGPT features
├── Copilot/         - GitHub Copilot for AI-assisted coding
├── Gemini/          - Google Gemini AI tools
└── Projects/        - Hands-on gen-AI coding projects
```

## How to Use This Repository

1. Pick an AI tool directory that interests you.
2. Read the `README.md` inside to get an overview of that tool.
3. Work through the examples and exercises with Claude's guidance.
4. Build your own projects in the `Projects/` folder.

## Getting Started with Claude

Claude is your primary assistant throughout this learning journey. Use it to:
- Explain concepts and code snippets
- Review and debug your work
- Suggest best practices
- Generate starter code for exercises

Happy learning! 🚀
